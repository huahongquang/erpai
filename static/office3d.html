Kết nối AI agents thực tế

Cung cấp địa chỉ WebSocket của hệ thống điều phối agent. Văn phòng sẽ cập nhật trạng thái, tiến độ và vị trí theo sự kiện được gửi đến. Không cần sửa giao diện.

Chưa kết nối. Hiện đang dùng dữ liệu mô phỏng.
// Ví dụ thông điệp JSON từ hệ thống AI orchestration: { "type": "agent_update", "id": "dev", "name": "Dev Agent", "status": "working", "task": "Xây dựng API khách hàng", "progress": 72 }
Trạng thái hỗ trợ: working, meeting, idle, done. Có thể gửi agent_add, agent_remove và log.
